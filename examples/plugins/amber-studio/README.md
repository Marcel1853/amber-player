# Amber Studio

30 Visualisierungen für Amber Player, die der Player nicht schon mitbringt. Die Klangeffekte stehen im zweiten Paket **Amber Studio Klang** (ein Paket darf höchstens 32 Teile haben). Alle Motive übernehmen die Akzentfarben des Players.

Aurora Flow · Particle Pulse · Cover Glow · Wasserfall · Tunnel · Skyline · Sternenreise · Feuerwerk · LED-Matrix · VU-Meter · Regen · Kaleidoskop · Synthwave · Puls · Galaxie · **Runner** (Spiel) · Matrix · Schnee · Schallplatte · Spirograph · Sonnensystem · Waben · Gebirge · Würfel · Gewitter · Pendelwelle · Glühwürmchen · Radar · Seifenblasen · **Raumschiff** (Spiel)

## Installation
Effekte → Installieren. Die Visualisierungen sind sofort in der Auswahl. Ältere Pakete mit gleichem Namen werden ersetzt, Amber Spectrum Studio und Amber Aurora FX vorher entfernen.
