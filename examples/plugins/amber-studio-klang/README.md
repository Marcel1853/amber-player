# Amber Studio Klang

20 Klangeffekte für Amber Player, die der Player nicht schon mitbringt. Gehört zu **Amber Studio** (Visualisierungen), ein Paket darf höchstens 32 Teile haben, deshalb sind es zwei Pakete.

Cassette Warmth · Dynamic Punch · Nachtmodus · Höhenglanz · Unterwasser · Overdrive · Loudness-Kontur · DJ-Filter · Glue-Kompressor · Zischlaute zähmen · Entdröhnen · Weichzeichner · Kleine Lautsprecher · Radiostimme · Kino · Gaming-Headset · Autofahrt · Rücksicht (Mietwohnung) · Mitsingen · Pfeifton-Filter

## Installation
Effekte → Installieren, Neustart, danach erscheinen die Klangeffekte.
